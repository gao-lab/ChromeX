# Model training

This directory contains the XGBoost model code used by ChromeX.

## Directory structure

```text
model_training/
├── README.md
├── ChromeX.py                      # main ChromeX model execution script
├── celltype_model.py               # cell-type-level XGBoost model execution script
├── results/                        # model output files and prediction results
├── src/                            # shared utility modules for model scripts
└── files/                          # configuration files used by model scripts
    ├── human_train_val_set.csv     # human training-cell list
    └── mouse_train_val_set.csv     # mouse training-cell list
```

## Input HDF5 files and saved model format

The modeling scripts take HDF5 files (e.g., `{celltype}_data.hdf5`), generated by the data processing workflows as input.

Models are saved using `joblib`. For reproducible prediction, use model files generated by the scripts in this repository.

## Cell-type-level model

This script trains a model from one HDF5 file and can apply a saved model to one HDF5 file.

```
Usage: 
python celltype_model.py -P PROCESS -m MODEL -o OUTPUT_DIR -c MODEL_CELL
                         [-C PREDICT_CELL] [-i TRAIN_PATH] [-I TEST_PATH] [-h]

Optional arguments:
-P/--process {train,predict}            Process type: (required)
                                        `train` for training model. 
                                        `predict` for predicting gene expression.
-m/--model MODEL                        Path to save the model files. (required)
-o/--output OUTPUT_DIR                  Path to save the result files. (required)
-i/--traindata TRAIN_PATH               Path to train data. (required when -P is "train")
-I/--testdata TEST_PATH                 Path to test data. (required when -P is "predict")
-c MODEL_CELL                           Cell type used to train the model. (required)
-C PREDICT_CELL                         Cell type for gene expression prediction. 
                                        (required when -P is "predict")
-h/--help                               Show this help message and exit.
```

**Example**

If the training input data file is `/absolute/path/to/A549_data.hdf5`, you can run the following commands to train the model:

```bash
python celltype_model.py -P train \
    -m ChromeX/model_training/files/A549_model.joblib \
    -c A549 \
    -o ChromeX/model_training/results \
    -i /absolute/path/to/A549_data.hdf5
```

Then, to predict gene expression, you can run the following command:

```bash
python celltype_model.py -P predict \
    -m ChromeX/model_training/files/A549_model.joblib \
    -c A549 -C A549 \
    -o ChromeX/model_training/results \
    -I /absolute/path/to/A549_data.hdf5
```

The trained model will be saved at `ChromeX/model_training/files/A549_model.joblib`, prediction output will be saved at `ChromeX/model_training/results/A549_gene_prediction_on_A549_model.txt`.

## ChromeX model

This script trains one model from multiple cells/datasets. It expects a dataset list and a directory containing HDF5 files named `{cell}_data.hdf5`.

Examples:

```text
/absolute/path/to/hdf5/A549_data.hdf5
/absolute/path/to/hdf5/K562_data.hdf5
/absolute/path/to/hdf5/GM12878_data.hdf5
```

Run the following commands to build the species-based model and to predict gene expression.

```
Usage: 
python ChromeX.py -D DATALIST -P PROCESS -m MODEL -n MODEL_NAME
                  [-N PREDICT_NAME] [-o OUTPUT] [-i TRAIN_PATH] [-I TEST_PATH] [-h]

Optional arguments:
-D/--dataset DATALIST                   Path to the dataset used for training and validation, 
                                        e.g., `human_train_val_set.csv`. (required)
-P/--process {train,predict}            Process type: (required)
                                        `train` for building model. 
                                        `predict` for predicting gene expression.
-m/--model MODEL                        Path to save the model files. (required)
-n/--modelname MODEL_NAME               Name of model. (required)
-N/--predictname PREDICT_NAME           Name of predicting data. (required when -P is "predict")
-o/--output OUTPUT                      Path to save the result files. (required)
-i/--traindata TRAIN_PATH               Path to train data. (required when -P is "train")
-I/--testdata TEST_PATH                 Path to test data. (required when -P is "predict")
-h/--help                               Show this help message and exit.
```

**Example**

If the training input data files are in `/absolute/path/to/input/`, ChromeX can be trained with the following commands:

```bash
python ChromeX.py -P train \
    -m ChromeX/model_training/files/ChromeX_human.joblib \
    -D ChromeX/model_training/files/human_train_val_set.csv \
    -o ChromeX/model_training/results \
    -i /absolute/path/to/input \
    -n human
```

Training output:

```text
{OUTPUT_DIR}/{MODEL_NAME}_model_performance.txt
```

And then, to predict gene expression, you can run the following command:

```bash
python ChromeX.py -P predict \
    -m ChromeX/model_training/files/ChromeX_human.joblib \
    -D ChromeX/model_training/files/human_train_val_set.csv \
    -o ChromeX/model_training/results \
    -I /absolute/path/to/input \
    -n human \
    -N human
```

Prediction scans all `.hdf5` files in `-I` and writes:

```text
{OUTPUT_DIR}/{PREDICT_NAME}_gene_prediction_on_{MODEL_NAME}_model.txt
```

Columns:

| Column | Description |
| --- | --- |
| `model` | Model name from `-n/--modelname`. |
| `predict_cell` | Cell/dataset name derived from the HDF5 filename. |
| `predict` | Predicted expression label. |
| `label` | Observed expression label from HDF5. |
| `isTrain` | `1` if the predicted cell is one of the training cells listed in `-D`, otherwise `0`. |
| `gene_name` | Gene name. |
