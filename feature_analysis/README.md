# Feature analysis

This directory contains scripts for interpreting trained ChromeX models and converting model-derived decision rules into biologically interpretable gene-feature patterns.

## Directory structure

```text
feature_analysis/
├── README.md
├── files/
├── results/
├── reference/
│   └── feature_index_name_association.txt   # maps feature index (f0, f1, ...) to biological feature names
└── scripts/
    ├── extract_decision_nodes.py            # extract XGBoost nodes, train node model, compute SHAP matrix
    ├── run_pca_snn_leiden.py                # PCA + SNN + Leiden clustering of genes
    ├── cluster_by_coassociation_matrix.py   # consensus clustering
    ├── find_differential_features.R         # identify cluster-specific differential decision-node features
    ├── run_fpgrowth.py                      # frequent itemset mining for representative decision-node feature combinations
    └── cluster_label_model.py               # train/predict gene-cluster label classifier
```

## Required inputs

| Input | Description |
|---|---|
| HDF5 data directory | Model-ready chromatin and RNA feature files generated by `../data_processing/` |
| Trained ChromeX model | XGBoost model generated by `../model_training/` |
| Training-cell list | CSV file containing the training cell or dataset names |
| `reference/feature_index_name_association.txt` | Feature-index annotation file used to map model features to readable biological names |
| `fpgrowth` executable | External frequent-pattern mining program required by `run_fpgrowth.py` |

## Usage

The complete feature-analysis workflow is provided in `run_feature_analysis.sh`. This script provides an example workflow covering decision-node extraction, node-level model prediction, SHAP matrix construction, Leiden clustering, consensus clustering, differential decision-rule detection, frequent rule-set mining and cluster-label model training.

Before running the workflow, open the shell script and modify paths such as the HDF5 directory, trained ChromeX model, input cell list, output folders and `fpgrowth` executable according to your local environment.

## Main outputs

Typical outputs include:

| Output | Description |
|---|---|
| `node_information_*.txt` | Selected XGBoost decision-node information by LASSO |
| `*_binary_mat.csv` | Gene-by-node binary matrix indicating whether each gene satisfies each decision node |
| `*_shap_mat.csv` | Gene-by-node SHAP matrix measuring node-level contribution for each gene |
| `leiden_assignments_*.csv` | Leiden clustering results across different resolutions |
| `consensus_leiden_assignments.csv` | Consensus clustering results |
| `cluster_*_final.txt.gz` | Frequent decision-node combinations for individual gene clusters |
| `gene_cluster_prediction_model.joblib` | Trained model for predicting gene-cluster labels |
